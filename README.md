# MeshNet

MeshNet is a home server application that moves data through processing pipelines as defined by the user. 

Input -> Process -> Output

Takes an input from a source then applies one or more transformations, writes the results to a destination. Sources, processors, and repositories are exposed through interfaces, keeping the core application independent from how data enters and leaves. 

# Goal

Do multiple inputs and outputs.

## Current inputs and outputs supported:
- CLI

- Memory
- File

# Status

MeshNet is currently under development. APIs and interfaces may change as the project evolves.
